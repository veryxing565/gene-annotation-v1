# Vendored workflow source

This is the selected BRAKER4 text-source snapshot used by the public wrapper,
not a separate upstream installation. It identifies itself as `0.5.0-beta`.
Use the top-level entry point and fixed EP/ETP profile; optional rule files
are retained for provenance but unsupported branches remain disabled, with
some unused helpers deliberately not distributed.

Original copyright and file-specific license notices remain in place.
See [third-party notices](../THIRD_PARTY_NOTICES.md),
[source checksums](../provenance/source_snapshot.json) and
[adaptation notes](../docs/UPSTREAM_PATCHES.md).
