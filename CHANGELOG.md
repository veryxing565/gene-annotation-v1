# Changelog

## 1.0.0rc1 — 2026-10-31

- Package the in-use EP/ETP BRAKER4-based uniform gene annotation and exact
  baseline/A–H TSEBRA panel as a configurable Linux source project.
- Preserve native compleasm hints and disable BUSCO-directed post-merge recovery.
- Retain independent compleasm 0.2.9 protein assessments and deterministic
  target/compactness-based profile selection with text reports.
- Replace site paths with manifests and explicit local dependencies; add CPU
  affinity, input/source fingerprints, owned scratch, checksum verification,
  serial failure handling and success-only cleanup.
- Provide English documentation, licensing, source provenance, synthetic tests,
  CI and reproducible source archives. No containers, datasets, keys or private
  study inputs are bundled. This is a release candidate, not a new predictor.
