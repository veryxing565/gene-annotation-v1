# Contributing

Open an issue with redacted configuration, package commit, versions and a
minimal reproducer before proposing a change to scientific behavior.
Run `python -m unittest discover -s tests -v` on Linux and rebuild the source
archives. Changes to vendored workflow files must retain upstream notices,
update source provenance and explain whether predictions can change.

Never submit credentials, GeneMark keys, containers, databases or research
data. Do not replace a tested version silently. Mocked tests and dry-runs must
be described as such, not as biological validation.
